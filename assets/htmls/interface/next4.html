Фрамингемская шкала: оценка индивидуального риска развития инсульта

В колонке «Выбор», при помощи выпадающих меню, выбрать нужные данные. Нажать кнопку «Подвести итог» для заполнения ячейки «Вывод».

Для добавления результата из ячейки «Вывод» в персональную программу индивидуализированной вторичной профилактики повторного сосудистого события пациента нажать на кнопку «+».

С подробной информацией можно ознакомиться в руководстве пользователя.
