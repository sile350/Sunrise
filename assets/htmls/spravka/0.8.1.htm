При клике левой кнопкой мыши по названию упражнения, происходит переход на страницу выполнения упражнения. Выполнение упражнений возможно на двух мониторах. Один для специалиста (с описательной частью и элементами управления), второй для пациента (выполнение упражнения). Описание упражнений смотри в разделе 14. Упражнения программы по восстановлению речевого мышления.

 

Дополнительные элементы управления

 Кнопка «+» для заголовка программы - для добавления даты, названия программы в раздел «Программа восстановления речевого мышления» персональной программы индивидуализированной вторичной профилактики повторного сосудистого события пациента, в личный кабинет которого осуществлен вход. Данные в разделе остаются доступны для редактирования (добавления, удаления) путем установки курсора и ввода с клавиатуры.

 Кнопка «+» для цели программы - для добавления цели программы (а также даты

и названия программы, если они не были добавлены ранее) в раздел «Программа восстановления речевого мышления» персональной программы индивидуализированной вторичной профилактики повторного сосудистого события пациента, в личный кабинет которого осуществлен вход. Данные в разделе остаются доступны для редактирования (добавления, удаления) путем установки курсора и ввода с клавиатуры.

 Кнопка «+» для упражнения - для добавления даты, названия программы, цели и названия упражнения (если дата, название программы и цель не были добавлено ранее) в раздел «Программа восстановления речевого мышления» персональной программы индивидуализированной вторичной профилактики повторного сосудистого события пациента, в личный кабинет которого осуществлен вход. Данные в разделе остаются доступны для редактирования (добавления, удаления) путем установки курсора и ввода с клавиатуры.
