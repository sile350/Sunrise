Упражнение «Составление рассказа» (описание)

·      Название упражнения: «Составление рассказа»

·      Источник описания:

·      Программы восстановления речевого мышления у больных с последствиями инсульта// Учебное пособие /М.М. Щербакова, С.В. Котов. М.: МОНИКИ, 2014.

·      Клепацкая Л.Б. Внимание, мышление, речь. Комплекс упражнений. Чать II. М.: В. Секачев, 2015.

·      Цель:

·      преодоление трудностей планирования и программирования речевого высказывания;

·      преодоление трудностей переключения;

·      самостоятельная речь.

·      Стимульный материал: инструкции по составлению рассказов; карточки рассказов с опорой на предметные картинки; рассказы из перепутанных предложений.

 

 

Процедура проведения (описание)

1.    Составление рассказа с опорой на предметные картинки. Прочитайте рассказ с опорой на предметные картинки.

2.    Составление рассказа из заданных предложений. Расположите предложения в нужной последовательности, чтобы получился связный рассказ.

3.    Самостоятельное составление рассказа. При помощи представленных инструкций составьте рассказ (рассказы).

     Вопросы к пациенту о том, почему он сделал то или иное действие, с целью повышения уровня осознания смысла задания и ориентировки в задании.

Выполнение упражнения

  Выбрать в меню номер упражнения, выбрать вариант задания при помощи кнопки «Следующее задание», и нажать кнопку «Начать упражнение» (или «F1» на клавиатуре) для отображения задания на экране пациента. Кнопка «F2» позволяет переключить экран пациента на экран специалиста и обратно). Выполнить задание согласно пункту «Процедура проведения».

 

1. Составление рассказа с опорой на предметные картинки

Экран специалиста                                                  Экран пациента

 

   Прочитайте рассказ с опорой на предметные картинки. Для перехода к следующему заданию данного упражнения воспользуйтесь кнопкой «Следующее задание».

 По окончании упражнения (после выполнения нужного количества заданий данного упражнения) специалист нажимает кнопку «Стоп» (или «F1» на клавиатуре), для оценки результата по выполненному упражнению. Произвести оценку результата, выбрав количество баллов. При необходимости выбрать характер деятельности, виды возможной помощи, и нажать кнопку «Сформировать протокол». Если требуется, заполнить оставшиеся ячейки протокола.

 Только после формирования протокола по выполненному заданию можно приступить к выполнению следующего!

 

 

2. Составление рассказа из заданных предложений

Экран специалиста                                                  Экран пациента

 

На обоих экранах отображаются предложения в нарушенной последовательности предложений (на экране специалиста так же отображается вариант с правильной последовательностью).

   Необходимо расположить представленные предложения в правильной последовательности (вверх – самое первое, вниз - последнее). Перемещение предложений осуществляется при помощи мыши с зажатой левой кнопкой (или перемещение пальцем на сенсорном мониторе). Все действия дублируются на экране специалиста.

   Если пациент считает, что выполнил задание, то должен нажать кнопку «Готово».

   Если рассказ собрано верно – форма с собранным рассказом на обоих экранах подсвечивается зеленым, раздается звук «Правильный ответ», упражнение засчитывается как выполненное верно.

Экран специалиста                                                  Экран пациента

   Если рассказ собрано неверно – форма с собранным рассказом на обоих экранах подсвечивается красным, раздается звук «Не правильный ответ», упражнение засчитывается как выполненное не верно.

Экран специалиста                                                  Экран пациента

 

Для перехода к следующему заданию данного упражнения воспользуйтесь кнопкой «Следующее задание». Для того, чтоб начать выполненное задание заново, нажмите на кнопку «Начать заново».

По окончании упражнения (после выполнения нужного количества заданий данного упражнения) специалист нажимает кнопку «Стоп» (или нажать клавишу «пробел» (space) на клавиатуре), для оценки результата по выполненному упражнению. При необходимости выбрать характер деятельности, виды возможной помощи, и нажать кнопку «Сформировать протокол». Если требуется, заполнить оставшиеся ячейки протокола.

 

 Только после формирования протокола по выполненному заданию можно приступить к выполнению следующего!

 

 

3. Самостоятельное составление рассказа

при помощи представленной инструкции

Экран специалиста                                                  Экран пациента

   На обоих экранах отображаются инструкции для помощи при составлении рассказа. Пациенту необходимо составить рассказ (рассказы) при помощи данных инструкций.

  По окончании упражнения (после выполнения нужного количества заданий данного упражнения) специалист нажимает кнопку «Стоп» (или «F1» на клавиатуре), для оценки результата по выполненному упражнению. Произвести оценку результата, выбрав количество баллов. При необходимости выбрать характер деятельности, виды возможной помощи, и нажать кнопку «Сформировать протокол». Если требуется, заполнить оставшиеся ячейки протокола.

 Только после формирования протокола по выполненному заданию можно приступить к выполнению следующего!

 

 После формирования протокола по всем выполненным заданиям, нажать кнопку «Подвести итог» под протоколом, чтобы заполнить ячейку «Итоговая оценка».
