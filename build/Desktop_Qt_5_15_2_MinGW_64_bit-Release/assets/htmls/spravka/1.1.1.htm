Упражнение «Выполнение речевых инструкций» (описание)

·      Название упражнения: «Выполнение речевых инструкций»

·      Источник описания: Программы восстановления речевого мышления у больных с последствиями инсульта// Учебное пособие /М.М. Щербакова, С.В. Котов. М.: МОНИКИ, 2014.

·      Цель:

·      затормаживание обильной непродуктивной речи и привлечение слухового внимания;

·      восстановление ситуативно обусловленной речи;

·      расширение объема слухоречевой памяти и восстановление фонематического восприятия.

·      Стимульный материал: простейшие речевые инструкции; ситуативные инструкции, связанные с бытовыми действиями.

 

 

Процедура проведения (описание)

   Озвучиваем пациенту простейшие речевые инструкции и ситуативные инструкции, связанные с бытовыми действиями. Они должны выполняться пациентом самостоятельно. Если у него возникают затруднения, специалист выполняет эти инструкции за него (предъявляет ему образец), после чего помогает выполнить инструкцию самостоятельно.

 

 

Оценка результата (описание)

3 балла (пациент выполнил все задания уверенно и за адекватный период времени)

2 балла (пациент выполнил все задания неуверенно и/или с задержками)

1 балл (пациент выполнил большую часть заданий)

0 баллов (пациент выполнил меньшую часть заданий, имеются неединичные ошибки, необходима посторонняя помощь)

-1 балл (пациент не справляется с заданиями, помощь малоэффективна)

Виды возможной помощи:

Стимулирующая помощь:

     Одобрение или неодобрение действий пациента, стимуляция с помощью слов «хорошо», «правильно», «неправильно».

Направляющая помощь:

     Вопросы к пациенту о том, почему он сделал то или иное действие, с целью повышения уровня осознания смысла задания и ориентировки в задании.

     Подсказка, совет действовать тем или иным образом.

Обучающая помощь:

     Показ способа выполнения задания с просьбой повторить это действие.

     Совместная деятельность: специалист помогает пациенту самостоятельно выполнить задание.

Логика заполнения протокола

Заполняется автоматически

Имя специалиста – ФИО, привязанное к логину, который использовался при входе в программу.

Результат: баллы (макс 3) - кол-во баллов дублируется из ячейки «Бал».

Ячейки «Характер деятельности», «Виды помощи» заполняются в зависимости от выбора специалистом соответствующих пунктов в разделе «Оценка результатов» либо самостоятельно.

Бал. – количество баллов, заполняется в зависимости от выбора специалистом соответствующего пункта в разделе «Оценка результатов» либо самостоятельно.

Остальные ячейки заполняются (правятся) специалистом самостоятельно.

 Кнопка «Настройки» - открывает доступ к настройкам, доступным для данной страницы.

 Кнопка «Уменьшить шрифт» - уменьшает шрифт на странице документа.

 Кнопка «Увеличить шрифт» - увеличивает шрифт на странице документа.

 

   Меню выбора сохраненных шаблонов с вопросами.

Позволяет выбрать и загрузить один из отредактированных и сохранённых пользователем шаблонов с вопросами.

После редактирования документа, открыть меню настроек, поставить курсор мыши в строку с названием шаблона (текст становится выделенным синим), ввести свое название для отредактированного документа и нажать кнопку «Сохранить». В дальнейшем этот шаблон будет открываться по умолчанию при выполнении задания. Для выбора другого шаблона нажать на стрелочку справа от названия используемого. Выполнение упражнения

   Нажать кнопку «Начать упражнение» (или «F1» на клавиатуре). Выполнить задание согласно пункту «Процедура проведения». На экране специалиста отображается список простейших речевых инструкций и ситуативных инструкций, связанных с бытовыми действиями. Специалист может использовать приведенные примеры речевых инструкций и/или дополнять/заменять их своими.

   Текстовый документ со списком инструкций аналогичен по использованию любому стандартному текстовому редактору. Возможно редактировать текст по усмотрению специалиста и сохранять его в качестве шаблона для дальнейшего использования (см. дополнительные элементы управления).

   По окончании упражнения (после выполнения нужного количества заданий данного упражнения) специалист нажимает кнопку «Стоп» (или «F1» на клавиатуре), для оценки результата по выполненному упражнению. Произвести оценку результата, выбрав количество баллов. При необходимости выбрать характер деятельности, виды возможной помощи, и нажать кнопку «Сформировать протокол». Если требуется, заполнить оставшиеся ячейки протокола.
